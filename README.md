# 상동역 롯데캐슬 시그니처 공식 분양 웹사이트

롯데캐슬 공식 브랜드 사이트(`https://www.lottecastle.co.kr/APT/AT00430/main/index.do`)의 디자인과 리소스를 반영하여, 요청하신 사항을 완벽하게 적용한 독립형 멀티페이지 분양 웹사이트입니다.

---

## 🌟 주요 개선 및 반영 사항

1. **폰트 완전 교체 (궁서/명조/세리프 100% 제거)**
   - 가독성이 뛰어난 최신 모던 산세리프 **`Pretendard`** 폰트로 100% 통일하였습니다.
2. **원래 공식 사이트 스타일의 조감도 & 시네마틱 글씨 이펙트 적용**
   - 메인 첫 화면에 롯데캐슬 공식 49층 랜드마크 조감도 비주얼 배치
   - 은은하게 빛나는 **골드 쉬머 텍스트 애니메이션** 및 순차적 Fade-In 모션 적용
3. **상단 GNB 메뉴 간소화 & 섹션별 개별 서브페이지 분리**
   - 상단 메뉴를 **[사업정보]**, **[단지정보]**, **[평면정보]** 3개 핵심 구조로 재편성
   - 각 메뉴 클릭 시 해당하는 전용 독립 페이지로 바로 이동
4. **공식 조감도, 단지배치도, 평면도 이미지 연동**
   - 롯데캐슬 공식 조감도, 7개동 단지배치도, 평면도(84A, 84B, 113, 121, 펜트하우스) 고화질 이미지 및 원본 확대 모달 탑재
